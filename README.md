Shopify Storefront

A custom Shopify storefront built with Next.js and TypeScript, designed to deliver a fast and responsive shopping experience while integrating third-party services for content management, customer engagement, and marketing automation.

The project uses Shopify for e-commerce operations, Prismic for content management, Klaviyo for email marketing, and Tidio for customer support chat.

Features
Fetch and display products using Shopify Storefront API
Infinite scroll product listing
Product detail pages with dynamic routing
Add to cart and redirect to Shopify checkout
CMS-managed content with Prismic
Email marketing integration with Klaviyo
Live chat support with Tidio
Skeleton loading states for better UX
Fully responsive design for mobile and desktop
Getting Started
git clone https://github.com/tunglam16402/shopify_store.git
cd shopify_store
npm install
npm run dev

Notes
Shopify handles checkout and order processing
Product data is fetched via Shopify Storefront API
CMS content is managed through Prismic
Klaviyo is used for email subscriptions and marketing flows
Tidio provides live chat support
SWR is used for data caching and revalidation
